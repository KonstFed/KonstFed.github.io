GRACG: Graph Retrieval Augmented Code Generation

Konstantin Fedorov, Boris Zarubin, Vladimir Ivanov · MAS-GAIN Workshop, ASEW 2025 Oral

  • Paper (DOI)
  • Code
  • BibTeX

In one paragraph

Code models that see only one file miss cross-file dependencies, and a whole repository does not fit in the context window. GRACG retrieves context using the structure of the repository: it builds a heterogeneous graph from the syntax trees of the code (files, classes, functions and the relations between them), learns node representations with GraphSAGE, and uses them to find the code a generation request depends on.

Main findings

  • Structure-aware retrieval improves retrieval metrics by 2–3 points over a dense UniXcoder baseline on RepoBench and on tasks derived from DevEval.
  • We convert DevEval into a Dockerized, EvoCodeBench-style benchmark, so generated repository-level code is evaluated by running it.

This paper extends my bachelor's thesis at Innopolis University.
