In one paragraph

A single sentence usually states several facts, so Open Information Extraction (OpenIE) has to return a set of (subject, relation, object) triplets. Autoregressive extractors are flexible but slow and repetitive; fixed-slot extractors are fast but lock the number of extractions at training time. DiffIE uses the randomness of discrete diffusion as the extraction mechanism itself. Each token gets one of four role tags (background, subject, relation, object). At inference we run n independent reverse-diffusion trajectories over these tags, all conditioned on one encoding of the sentence, and cluster the resulting candidate triplets. Both the number of trajectories and the number of returned triplets are chosen at inference time.

Main findings

  • Results. Best reported CaRB (1-1) F1 and AUC, best BenchIE F1, and the best average among systems that report all four benchmarks. Not best everywhere: it trails on standard CaRB and WiRe57.
  • Uniform beats absorbing noise. With only four tags, uniform-noise diffusion (D3PM) outperforms masked diffusion (MDLM) by 2–3 F1.
  • The gain comes from diffusion. A matched stochastic tagger with the same encoder, sampling and clustering does not reproduce the results.
  • Compute is a dial. Going from 16 to 512 samples adds about 3 F1 with the same weights, no retraining.
